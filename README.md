# Comprobify ERP

Cloud ERP for small and medium Ecuadorian businesses, built around SRI electronic invoicing. One Next.js app and one worker share a TypeScript core and one PostgreSQL database.

Under construction. It replaces the separate `comprobify` API and `comprobify-web` systems.
